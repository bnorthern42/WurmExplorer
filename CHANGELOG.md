## [1.0.1] - 2026-10-04

### Fixed
- Explicitly defined CMake modules for OpenCV 5 fallback to resolve target guessing failures on MSYS2 and macOS.

## [1.0.0] - 2026-10-04

### Added
- Computer Vision Treasure Map Locator using multi-scale template matching and OCR.
- Interactive Map Canvas with Pan, Zoom, Multi-layer Drawing, and Annotations manager.
- Sailing Route Planner & Cluster Navigator with cross-server topology visualization.
- Mechanics Grinder Simulator with Monte Carlo probability simulation for 14 Wurm Online action modes.
- Bridge Dirt Pillar Calculator with Chebyshev distance modeling and PvP slope rule support.
- Granger Livestock evaluation engine with trait genetics and breeding compatibility scoring.
- Real-time Skills Tracker with client log tailing and session gain rate analytics.
- Modern Dark Slate & Emerald design system and ThemeTokens.
- Cross-platform support for Linux, Windows (MSYS2 UCRT64/MINGW64), and macOS (Homebrew).
- Multi-OS automated build matrix in GitHub Actions with native binary releases.
- Universal dependency installation scripts (`scripts/install_dependencies.sh` and `scripts/install_dependencies_windows.sh`).
- CLI interface with window geometry sizing (`--size`, `--half-screen`, `--fullscreen`, `--maximized`), direct tab launch (`--tab`), and headless docs capture (`--capture-docs`).
- Full project documentation, community health guidelines, AppImage packaging, and container support.
